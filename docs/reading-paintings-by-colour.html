What the tool does today

Image Colors, 2025
web application · runs in the browser

You give it a photograph of a painting. It finds the dozen or so colours that make up the picture and measures how much of the canvas each one covers. It then gives every colour two names: the closest of thirty-two parent colours (Red, Navy, Olive …), and the closest colour from a large list of named reference colours (the “Pantone match”). You can save a set of paintings together under a name and come back to it.

That is the right shape for what you want to do — walk through a museum, run every work, and see how the colours of a room, a period or an artist add up. The rest of this document is about making the numbers trustworthy enough to build a study on.

How a machine sees colour

CIELAB · ΔE₀₀
the ruler underneath everything

Computers store colour as red, green and blue light. That is how screens work, but it is not how eyes work: equal steps in RGB are not equal steps in what you see. So the analyser converts every pixel into a colour space designed around human vision, called Lab, with three axes — L from black to white, a from green to red, b from blue to yellow.

In that space, the distance between two colours is meant to match how different they look. The distance has a name, ΔE (“delta E”), and the version we use (ΔE₀₀, from 2000) is the one colour scientists and the paint industry agree on. Roughly:

0.6ΔE₀₀

Invisible. Two colours most people cannot tell apart even side by side.

2.9ΔE₀₀

Just noticeable when the two touch. About the tolerance a printer works to.

8.0ΔE₀₀

Clearly a different shade of the same colour — a lighter, softer ultramarine.

17.8ΔE₀₀

A different colour. Nobody would call these the same blue.

30.3ΔE₀₀

Navy and dark grey. The old matcher sometimes confused these — the fix is a better set of families, not a cleverer formula.

Every match the tool makes is a ΔE. A small number means the parent-colour name fits; a large one means the colour sits between two parents and a person should look. The app calls those problematic matches, and the new version will put them in front of you rather than hide them.

What is honestly wrong right now

from the technical audit
plain language

I went through the code line by line. Some of what follows will be uncomfortable; all of it is fixable, and none of it means the idea was wrong.

Same painting, slightly different answer

Run the same photograph twice and the colours and percentages shift a little, because the grouping starts from random points. Hiren likes seeing that variation — it shows what is solid and what is marginal — so it stays, with an optional “repeatable run” switch for when a study needs identical numbers.

After

Variation by default, exactness on demand: flip one switch and the same photo gives the same result every time.

The percentages use a different ruler than the grouping

Colours are grouped in Lab, the space built for eyes — but the percentages are then counted in RGB, the space built for screens. The two disagree, so the shares you see belong to slightly different groups than the colours you see.

After

One ruler throughout. Shares add up to exactly the visible surface of the painting.

The thirty-two families are web colours

They are the named colours of web browsers — pure #FF0000 red, #00FF00 green. Almost nothing in a museum is that saturated, so real pigments get pushed toward the nearest neon.

After

A set of parent colours chosen by a painter — you — and versioned, so a study done in 2027 stays comparable with one from 2026.

“Learning from feedback” never learned

Three attempts were built to let the tool improve from human corrections. None can save a correction: one is rejected by the server every time, one is never sent, one talks to an address that does not exist. Nothing you ever taught it was kept.

After

Every correction you make is stored, with who made it and against which version of the parent-colour list — and we measure whether the tool actually agrees with people more over time before we call it learning.

Saved collections live on borrowed ground

Your saved sets sit in a content system we are replacing, behind a password that is also written into the app itself.

After

Presets, images and results live in the system Hiren already runs for your portfolio site, under your login.

What it becomes

Image Colors 2.0
a museum workflow

The new version is organised the way you work: a preset (a room, an exhibition, an artist) holds the images you analysed, each with its wall-label details and a record of exactly which settings produced its result.

  1. Photograph

    Any camera. If the file carries a colour profile, we will honour it instead of ignoring it.

  2. Label

    Title, artist, year, inventory number — the same fields as the card on the wall. Fill them once for a whole batch.

  3. Analyse

    Drop forty photographs at once. Each becomes a set of colours with percentages, parent-colour names and ΔE distances.

  4. Review

    A queue shows only the problematic matches. Accept or correct each with one key. Your feedback is kept.

  5. Compare

    A room summary: which parent colours dominate, side by side with another room, period or artist.

  6. Export

    A board per painting, a spreadsheet per preset, a PDF summary for a curator.

Where your eye is needed

three decisions
only you can make

The parent colours

The single most important decision. Which twenty-or-so parent colours should every extracted colour be sorted into? A painter's set — earths, a warm and a cool red, an ultramarine and a Prussian, bone black and lead white — will describe a museum far better than the browser's set. In a working session we place them together and the tool shows the ΔE between neighbours so that no two parent colours sit closer than about 10.

Sixteen sketched parent colours — a conversation starter, not a proposal. The list we ship is yours.

Twenty test paintings

Photographs of works whose palette you know well. They become the yardstick: if the tool's result surprises you, the tool is wrong.

The words

Parent-colour names, and later the mood vocabulary. If “Ochre” means something specific to you, the tool should say Ochre, in Dutch and English.
